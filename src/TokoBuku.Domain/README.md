# 🏛️ TokoBuku.Domain

Core enterprise layer within the **Clean Architecture**.

### Layer Scope:
- **Entities**: Enterprise core business models (`Book`, `Category`, `Customer`, `Sale`, `Supply`, `Supplier`).
- **Enums**: Enumeration types for transaction states and business classifications.
- **Exceptions**: Domain exceptions enforcing business invariants.
- **Common**: Base entity, auditing contracts, and domain events.

> 🔒 *Portfolio Notice: Implementation files (`*.cs`) in this layer are maintained in a private repository to protect proprietary business logic.*
